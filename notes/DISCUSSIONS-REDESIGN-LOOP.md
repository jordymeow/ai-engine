# Discussions screen redesign loop

Started 2026-09-15 at Jordy's request: the Discussions list is messy, noisy, with columns too narrow (words broken mid-letter) and others overflowing with text. Be creative, try different layouts, never commit. Loop every 15 minutes (cron e3d062f0) for 1 to 2 hours, until it feels finished.

Screen: AI Engine → Discussions on ai.nekod.net. Code: `app/js/screens/discussions/` (Discussions.js, ExportModal.js, DeleteModal.js). Build with `pnpm build`.

## What must keep working
- Filters (user text, chatbot select, preview text), sort by time, paging, Export, Delete selected, Delete all (modal), Refresh, Auto Refresh
- Row click selects one discussion, checkboxes select several, the side panel shows the selected discussion, Full Screen view, sidebar collapse toggle
- No em-dashes in UI copy, no console errors

## Checklist
- [x] Words never break mid-letter; nothing wraps into 3+ lines
- [ ] Each row readable at a glance: who, which bot, what was asked, what was answered, when
- [x] Previews cleaned: markdown images and links, whitespace, duplicates of the same message
- [x] Time is short and scannable, full date on hover
- [x] Chatbot shown compactly, technical IDs out of the way
- [x] Selected Discussion panel: useful empty state, readable conversation, metadata tidy
- [x] Works at narrow widths (sidebar open, laptop screen)
- [x] Full Screen view still consistent with the new look
- [x] Regression pass: filters, paging, export, delete, refresh, selection
